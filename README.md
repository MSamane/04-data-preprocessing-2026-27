# Lecture 4: Data Preprocessing

Data Science and Machine Learning for Geoscientists  
Academic year: 2026–27  
Lecturer: Samaneh A. Mofrad

## About this lecture

Using marine sediment data, we practise removing duplicates, handling missing
values, splitting training and test sets, scaling data and building
scikit-learn pipelines.

Open [01-Data-Preprocessing.ipynb](01-Data-Preprocessing.ipynb) in JupyterLab,
Jupyter Notebook or VS Code with a Python 3 kernel. Keep the `Datasets` folder
beside the notebook. Required libraries: NumPy, pandas, Matplotlib and scikit-learn.

## Download the materials

You have two options. Neither requires a GitHub account for this public repository.

### 1. Download ZIP

Click **Code → Download ZIP**, unzip the folder, then open the notebook locally.

### 2. Use Git

[Install Git](https://git-scm.com/install/) if needed, selecting your operating system.

Click **Code → HTTPS**, copy the repository link, then run this in a terminal,
replacing the placeholder with the copied link:

```bash
git clone PASTE_THE_COPIED_LINK_HERE
```

Open the notebook inside the downloaded folder. To get later updates without
downloading the whole repository again, run this **inside the cloned folder**:

```bash
git pull
```

For either option, work in a separately named copy of the notebook in the same
folder, keeping the original unchanged. Git updates will not update your personal
copy. You do not need to fork the repository or push your work.
